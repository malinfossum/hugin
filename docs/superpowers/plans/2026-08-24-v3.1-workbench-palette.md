- [ ] **Step 2: Replace the default block in colors.css**

Replace the entire `[data-palette="default"], html:not([data-palette])` block (and its light-mode sibling) at the bottom of `tokens/colors.css` with the blend. Rewrite the long explanatory comment above the block to describe the new identity (keep its structure: why the plain `:root` is untouched, why the selector pair is mutually exclusive with named palettes, why `--on-accent` is hardcoded). New values:

```css
[data-palette="default"],
html:not([data-palette]) {
	/* Kenaz ground — true-black page, warm near-black surfaces. */
	--surface-0: #000000;
	--surface-1: #000000;
	--surface-2: #0b0a09;
	--surface-3: #14110d;
	--surface-4: #1d1811;
	--surface-5: #262016;

	/* Kenaz text + borders (border #322b22 holds WCAG 1.4.11 parity — see kenaz.css). */
	--text: #f4efe6;
	--text-muted: #b8ada0;
	--text-faint: #8f8578;
	--border: #322b22;
	--border-strong: #3a3226;
	--border-soft: #1c1813;

	/* Accent: midpoint of Kenaz (217 154 78) and Gold (227 179 65). */
	--accent-rgb: 222 166 72;
	--accent-strong-rgb: 234 186 98;

	/* Amber is light enough for dark ink (same reasoning as kenaz.css). */
	--on-accent: #241704;
}

[data-theme="light"][data-palette="default"],
html[data-theme="light"]:not([data-palette]) {
	/* Midpoint of the kenaz and gold light-mode accents. */
	--accent-rgb: 163 112 26;
	--accent-strong-rgb: 134 90 18;
	--accent-solid: #8c6016;
}
```

Note: unlike the old Daily block, no dark-mode `--accent-solid`/`--accent-solid-strong` overrides — with a light amber accent and dark ink, the derive-from-accent formula in `:root` passes (same as Kenaz). The light block's `--on-accent` is deliberately not restated (the `:root[data-theme="light"]` rule supplies white — same note as kenaz.css).

- [ ] **Step 1: Rework hugin.css**

Replace the value block (keep the file structure: dark block, heading rule, light block). Direction per spec item 1: deeper ground, wider surface steps, brighter muted text, stronger borders, hotter accent. Starting values (these ARE the deliverable — tune only if the gallery check in step 2 shows an obvious miss; Malin's visual verdict at the end of the wave decides final adjustments):

```css
[data-palette="hugin"] {
	/* Deeper ground, wider steps — panels visibly lift off the page. */
	--surface-0: #000000;
	--surface-1: #0a0806;
	--surface-2: #16100a;
	--surface-3: #1e1610;
	--surface-4: #2a1f14;
	--surface-5: #362a1a;

	/* Brighter text ramp than the OLED foundation — less blending. */
	--text: #fbf7ef;
	--text-muted: #cfc5b4;
	--text-faint: #9a9080;

	/* Stronger borders so cards/inputs read as edges, not smudges. */
	--border: #3a3126;
	--border-strong: #4a3f2e;
	--border-soft: #241d15;

	/* Ember accent, turned up. */
	--accent-rgb: 214 106 48;
	--accent-strong-rgb: 232 128 64;

	/* Type skin — Space Grotesk headings, Figtree body (both bundled). */
	--font-sans: "Figtree", ui-sans-serif, system-ui, -apple-system, "Segoe UI", sans-serif;
	--font-display: "Space Grotesk", "Figtree", sans-serif;

	/* Solid-button ink — ember is mid-tone, deepen the fill for white text at AA. */
	--on-accent: #ffffff;
	--accent-solid: #a34014;
	--accent-solid-strong: #b84d1c;
}

[data-palette="hugin"] h1,
[data-palette="hugin"] h2,
[data-palette="hugin"] h3,
[data-palette="hugin"] h4 {
	font-family: var(--font-display);
}

/* Light mode keeps the base light surfaces; ember tuned for contrast on white. */
[data-theme="light"][data-palette="hugin"] {
	--accent-rgb: 158 62 22;
	--accent-strong-rgb: 132 50 16;
}
```

Update the header comment: no longer "daily-derived v1 … dedicated branding pending" — this is Hugin's own hardened identity (still ember-family).
