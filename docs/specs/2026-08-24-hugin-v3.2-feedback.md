## Header sources (the big one)

6. **Configured links become their own customizable section.** Today the sources row mixes the two fixed data sources with whatever linkouts sit in hugin.json — a new user gets Malin's Innlandet/IT deep links and can't change them from the UI. New model:
   - **Fixed:** Brønnøysundregisteret + NAV stay always-on (they are the data sources).
   - **Default demo links for everyone:** FINN, LinkedIn, **Proff** — pointing at the GENERIC job-search front pages (no fylke/kommune/category baked in); they demonstrate the feature and are useful as-is.
   - **User-customizable:** users add/edit/remove their own links (Malin wants to add e.g. "kodejobb" and "tekjobb"; her Innlandet deep links become her personal entries). Place the section on its own (own card, or under "Sync now" with more separation).
   - Implies UI-editable persistence → see item 8 (Settings). Recommended storage: the db (a Sources table seeded with the defaults), not hugin.json — the UI owns it, the config file stays machine-edited. hugin.json `linkouts` can seed/import on first run for backward compat.
